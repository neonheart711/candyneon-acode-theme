# Candy Neon

A high-contrast, softly colorful, eye-catching theme for **Acode**.

Candy Neon combines deep near-black backgrounds (`#12101c`) with crisp near-white text (`#f5f3ff`) to create a clean, readable editing experience. A vibrant candy-neon palette—pink, cyan, violet, lime, yellow, and orange—adds color and personality without sacrificing contrast or long-session comfort.

## Features

- **Complete app UI theme** — buttons, popups, dialogs, scrollbars, borders, links, and more.
- **Custom editor syntax theme** — full CodeMirror highlighting for keywords, strings, numbers, comments, functions, types, tags, constants, and errors.
- **High contrast** for excellent readability.
- **Soft neon colors** that remain comfortable during extended coding sessions.

## Installation

1. Download `candy-neon-theme.zip`.
2. Open **Acode** → **Settings** → **Plugins**.
3. Choose **Install from device** and select the ZIP file.
4. Apply the themes:
   - **Settings → Themes → Candy Neon**
   - **Settings → Editor Settings → Editor Theme → Candy Neon**

## Why Candy Neon?

If you enjoy dark themes but want something more vibrant than the typical monochrome editor, Candy Neon offers a balanced mix of **clarity, color, and comfort**—making code easier to read while giving your editor a distinctive neon-inspired look.
